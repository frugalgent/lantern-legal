# Lantern — Legal

Public hosting for the Lantern app's **Privacy Policy** and **Terms of Service**.

- https://frugalgent.github.io/lantern-legal/privacy/
- https://frugalgent.github.io/lantern-legal/terms/

These pages are **generated** from the source Markdown in the private Lantern
app repo (`legal/*.md`) via `scripts/build-legal.mjs` (`npm run docs:legal`),
then copied here and pushed. GitHub Pages serves this repo from the `main`
branch root.

To update: edit the Markdown in the app repo, rebuild, copy the generated
files here, and push.
